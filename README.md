# FFIProbe

A tool for detecting memory safety bugs in Rust multilingual programs.

## About

FFIProbe is a prototype designed to identify memory safety bugs in
the interaction between Rust and other languages through FFI
(Foreign Function Interface).

## Project Structure

The repository is organized as follows:

- **`rust-src/`** - The Rust source code of FFIProbe, based on Rust nightly-2026-01-10
- **`changes.diff`** - The diff file of changes made to the Rust source code
- **`scripts/`** - Scripts for building datasets and running evaluations
- **`dataset/`** - Evaluation datasets for FFIProbe
- **`trophy_case/`** - Notable test cases and findings
- **`results.db`** - Database for recording evaluation results (generated by `scripts/run.py`)

## Usage

To use FFIProbe, follow these steps:

1. Build FFIProbe from `rust-src/` using the 
[Rust Compiler Development Guide](https://rustc-dev-guide.rust-lang.org/building/how-to-build-and-run.html).
2. Register the built compiler as a custom `rustup` toolchain, 
for example: `rustup toolchain link ffiprobe /path/to/ffiprobe-build`
3. In the package you want to test, enable the FFIProbe feature
by adding `#![feature(ffi_sanitizer)]` to the crate root (`main.rs` or `lib.rs`).
4. Run the package with the custom toolchain:
   - `cargo +ffiprobe run`
   - `cargo +ffiprobe test`

FFIProbe will report detected memory safety issues to the console during execution.
